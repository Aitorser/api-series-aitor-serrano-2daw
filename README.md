# Aplicación Angular — Examen DWEC

Aplicación de página única (SPA) desarrollada con **Angular** como examen del segundo
trimestre de la asignatura DWEC (Desarrollo Web en Entorno Cliente), del ciclo de
Desarrollo de Aplicaciones Web (DAW).

> Proyecto de aprendizaje. Lo mantengo público como muestra de mi trabajo con Angular
> y TypeScript.

## Qué demuestra

- Desarrollo de una SPA con **Angular** y **TypeScript**.
- Organización en componentes y estructura estándar de proyecto Angular.
- Flujo de **integración/despliegue con GitHub Actions** (`.github/workflows`).

## Tecnologías

- Angular
- TypeScript
- HTML5 y CSS3
- Angular CLI
